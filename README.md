# 🌟 Aithink

**Aithink** is a modern and elegant UI component designed for seamless interaction with artificial intelligence. It allows users to type prompts, receive real-time responses, and enjoy a smooth, intuitive experience. The project combines sleek design with advanced functionality to make AI interaction effortless.

---

## 🚀 Features

* **💬 Interactive Prompt Component:** Type and send prompts to AI with ease.
* **⚡ Real-time Responses:** Instant display of AI-generated answers.
* **🕘 Conversation History:** Keep track of all previous interactions.
* **🎨 Modern Design:** Clean, responsive, and user-friendly interface.
* **✨ Animations:** Smooth transitions and effects with Framer Motion.

---

## 🛠 Technologies Used

* **Frontend:** React.js / Next.js
* **Styling:** TailwindCSS
* **UI Components:** shadcnUI
* **Animations:** Framer Motion

---

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/HasinaSyl20/Aithink.git
```

2. Install dependencies:

```bash
cd Aithink
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

---

## 📝 Usage

* Type your prompt in the input field.
* Press **Enter** or click the **Send** button.
* Instantly see AI responses displayed dynamically.
* Scroll through previous prompts and responses in the conversation history.
